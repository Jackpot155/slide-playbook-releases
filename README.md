**Slide Playbook**
The Ultimate Slide-by-Slide Presentation Companion

Official release repository for **Slide Playbook**. 
Download the latest cryptographically signed Android builds directly onto your device.

How to Download & Install
1. Navigate to the **[Latest Release](../../releases/latest)** section on the right side of this repository.
2. Under **Assets**, tap **`app-release.apk`** to download the installation file.
3. Open the downloaded `.apk` file on your Android device.
4. If prompted, allow installation from unknown sources in your browser/file manager settings.
5. Tap **Install** and launch Slide Playbook!

Features
* **Dynamic AI Integration:** Fast, responsive slide and presentation workflows powered by Gemini.
* **Seamless Local Experience:** Lightweight, fast performance optimized for modern Android devices.
* **Verified Builds:** Every release is automatically compiled and cryptographically signed via GitHub Actions.
  
System Requirements
* **OS:** Android 8.0 (API Level 26) or higher
* **Storage:** ~15 MB free space
* **Internet Connection:** Required for online model features
